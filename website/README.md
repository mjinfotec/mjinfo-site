# MJ INFO Institucional

Site institucional premium para a MJ INFO / MJ Informatica, construido com Next.js, React,
TypeScript, Tailwind CSS, Framer Motion e componentes reutilizaveis.

## Rodar localmente

```bash
npm install
npm run dev
```

## Build de producao

```bash
npm run build
npm run start
```

## Estrutura

- `app/`: paginas do site e metadados SEO.
- `components/`: componentes reutilizaveis de layout, CTA, cards, FAQ e animacoes.
- `data/site.ts`: conteudo institucional, navegacao, servicos, blog e configuracoes.

## Páginas

- Home
- Sobre a MJ INFO
- Blindagem Digital
- Protecao Familiar
- Protecao para Empresas
- Educacao Digital
- Blog / Artigos
- Contato
- Diagnostico Digital
